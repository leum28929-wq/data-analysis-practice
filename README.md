# data-analysis-practice

## 프로젝트 목적
본 프로젝트는 데이터 분석 수업에서 진행한
기본 시각화 실습 결과를 정리하기 위해 수행되었다.

## 사용 데이터
- 서울특별시 공공자전거 일별 대여건수

## 분석 및 시각화 내용
- 날짜별 따릉이 대여건수 및 7일 이동평균 변화 (선그래프)
- 따릉이 일별 대여건수 변화 (히스토그램)
- 요일별 평균 따릉이 대여건수 (막대그래프)
- 월별 평균 따릉이 대여건수 (막대그래프)

## 사용 도구
- python
- pandas
- matplotlib
- seaborn

## 결과 요약
9월에 가장 많은 대여량을 가지고 12월에 가장 적은 대여량을 가진다.
평일과 비교했을때 주말 대여량이 더 적다.
기상 요인과 이용 목적에 의해 공공자전거의 대여 건수에 변동이 생긴다.

## 느낀점
분석 목적에 맞게 데이터를 활용하여 보여주기 위해서 의문에 부합한 종류의 그래프를 제공하는 것이 중요하다.
